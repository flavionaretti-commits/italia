ITALIA! – PWA v1.0

CONTENUTO
- Regioni: nome -> carta e carta -> nome
- Capoluoghi di regione: nome -> carta con punteggio di precisione; carta -> nome
- 1–6 giocatori
- stesso numero di domande per giocatore
- 5 / 10 / 20 / 30 domande
- timer opzionale con bonus velocità
- modalità Allenamento
- giorno/notte, suoni, regolamento, info e crediti
- dati e impostazioni locali sul dispositivo
- PWA offline tramite service worker

TEST RAPIDO
Apri index.html per provare la logica. Per installarla come PWA è necessario servirla via HTTPS
(ad esempio con GitHub Pages), perché il service worker non funziona da file://.

NOTA CARTOGRAFICA
Questa v1.0 usa una vettorializzazione della carta muta fornita nel progetto. Per una pubblicazione
definitiva conviene sostituire il tracciato con dati amministrativi open data ISTAT, mantenendo invariato
il motore di gioco.
